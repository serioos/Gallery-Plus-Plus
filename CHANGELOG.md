# Changelog

## 1.0.0 - Gallery++

- Initial Gallery++ release based on the SillyTavern Gallery 1.6.2 code supplied for this fork.
- Left-click opens the clicked media on the left side.
- Right-click opens the clicked media on the right side.
- Right-click resolves the clicked thumbnail by its actual source URL.
- Updated third-party asset/import paths for GitHub installation.
- Added standalone settings/UI namespacing and legacy settings migration.
